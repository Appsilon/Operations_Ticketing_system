# HelpSpot – K.O. screen
1. Products evaluated: **HelpSpot** (UserScape, Inc.), one plan with every feature at every agent tier. Evaluated as the vendor-hosted **EU Cloud** (AWS Frankfurt). US Cloud and Self-Hosted have the same price and features; where self-hosting changes something, the row says so. Docs describe version 5.8.x (release notes list 5.8.10).
2. Checked: 2026-11-18
3. Summary: Meets 7 / Partial 8 / Does not meet 0 / Unknown 1 (of 16). Lowest plan meeting the most criteria: **the single HelpSpot plan** (no feature tiers). Price: US$2,199 / year for the 10-agent tier (US$18.33 / agent / month, billed annually). About 11 agents (user assumption) need the 15-agent tier: US$3,199 / year (US$17.78 / agent / month).

## Single tool for internal + external?
1. **The vendor positions HelpSpot for both.** "Whether you're supporting employees or customers, HelpSpot adapts to your unique workflow INTERNAL SUPPORT IT Service Desk … HR Service Desk … CUSTOMER SUPPORT B2B Customer Support" ([Home](https://www.helpspot.com/)). IT page: "Employees email IT or use a portal." ([IT Service Desk](https://www.helpspot.com/solutions/it-service-desk)).
2. **Several departments in one instance are documented.** Option 1: "Create limited permission groups so department staff only see requests in their assigned categories". Use it when "Requests are expected to be passed back and forth between departments". Caveat: "Any admin in the system can access all requests." Option 2 is a "separate HelpSpot instance per department" for stronger separation ([Admin Manual §4.15](https://support.helpspot.com/index.php?pg=kb.printer.friendly&id=1)).
3. **The internal side is weakest on approvals and Slack.** No approval feature was found (#10). Slack works only through Zapier or a custom build (#23), and employees use Slack first. The client side (email, about 80% of Platform traffic) is the product's core: "HelpSpot is optimized for email-based exchanges" ([Users Manual §1.1](https://support.helpspot.com/index.php?pg=kb.printer.friendly&id=12)).

## Free trial
Yes. **21 days**, "NO CREDIT CARD REQUIRED", on the full product (single plan). It runs in the cloud or as an on-premise download ("Download on-premise or start in the cloud today"). After the trial: "Purchase a subscription and continue where you left off … If you choose not to continue, your trial data will be deleted." Paid plans also have a "90-Day Guarantee" ("Full refund within 90 days"). Hosted-trial limit: "if you're on a hosted trial, you'll need to contact support to enable editing of portal templates" (Admin Manual §5.1). Sources: [Pricing](https://www.helpspot.com/pricing), [llms-full.txt](https://www.helpspot.com/llms-full.txt), [Admin Manual](https://support.helpspot.com/index.php?pg=kb.printer.friendly&id=1).

# OTRS – full screen (requirements outside the K.O. set)
1. Products evaluated: OTRS by EasyVista-OTRS GmbH (otrs.com footer: "© 2026, EasyVista-OTRS GmbH"), release line 2026.x. Evaluated first: **OTRS Managed** (vendor-hosted SaaS, "By default, data is stored on servers in Germany (on request in USA or Canada)"). OTRS On-Premise is noted where it changes a verdict (it changes none of the 43). Packages: Starter / Advanced / Pro, prices not public ("Get a quote"). Extras: "AI Credits", "Storage", "Asset/CI", "SMS Alert", "Pulse AI Enablement", "On-Premise Services", "OTRS Premium Services" (no prices). Trial: "Want to try OTRS for free? Let us know, and we'll set up a trial instance for you." Sources: https://otrs.com/how-to-buy/ ; https://otrs.com/otrs-software-solutions/otrs/otrs-on-premise-managed/
2. Checked: 2026-11-18
3. Summary: Meets 19 / Partial 23 / Does not meet 0 / Unknown 1 (of 43). Must have (13 of the 43: #2, #7, #8, #11, #14, #18, #19, #20, #21, #22, #24, #25, #28): Meets 6 / Partial 6 / Does not meet 0 / Unknown 1.

Notes on method:
1. Main sources are the vendor's PDF manuals on academy.otrs.com: Administration Manual Release 2025.6.1 (ADMIN, https://academy.otrs.com/wp-content/uploads/otrs_admin_manual_en.pdf), User Manual Release 2025.8.1 (USER, https://academy.otrs.com/wp-content/uploads/otrs_user_manual_en.pdf) and Features Manual Release 2025.1.1 (FEATURES, https://academy.otrs.com/wp-content/uploads/otrs_fao_manual_en.pdf). Section numbers are given in the Source column. The manuals are older than the current release (2026.8.x); newer features come from the release notes on otrs.com.
2. Blocked or unavailable: the HTML docs on academy.otrs.com return "NinjaFirewall 403 Forbidden" to the headless browser; doc.otrs.com returned HTTP 502 ("upstream request failed"); the roadmap (https://otrs.com/otrs-software-solutions/otrs/roadmap/) shows its content only after accepting a third-party service (not clicked). The three PDF manuals on the same academy.otrs.com host downloaded normally with the same browser (HTTP 200, no spoofing). otrs.com showed "One moment, please..." on the first request; it cleared by waiting.
3. "Lowest plan": the pricing page lists only package-level items (Starter: "Core functions Ticketing Workflows Asset Management (1,000)"; Advanced adds "Kanban View Webservices Test system"; Pro adds "Unlimited Assets 24x7 Support 12,000 AI Credits EV Reach User License"). "Starter (core Ticketing/Workflows)" in the table is my mapping of a core feature to that list, not a vendor statement per feature. The Features Manual uses older package names (SILVER, GOLD, TITANIUM, PLATINUM); how they map to Starter / Advanced / Pro is not published.
4. Managed (SaaS) caveat: several admin functions are run by the vendor for Managed customers ("If you are a Managed customer, this feature is taken care of by the Customer Solutions Team in OTRS"), for example incoming/outgoing email setup, agent and customer back ends (LDAP/SSO), Data Privacy Protection, attachment deletion and the Package Manager (ADMIN §3.6.3, §3.9.3, §4.1.4, §4.5.3, §12.17, §12.19, §10.7).
5. Integrations: the API route is the Generic Interface (REST/SOAP web services), which the pricing page lists under Advanced ("Webservices"). Rows that rely on a custom build therefore need at least Advanced.
